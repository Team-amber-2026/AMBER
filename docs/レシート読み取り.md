# 機能仕様：レシート読み取り（OCR）

## 概要
Reactで取得した画像をTesseract.jsでブラウザ内解析し、確認済みの支出データだけをDjango REST APIへ送信する。

## ワークフロー
1. **Frontend**: `input type="file"` またはカメラ起動で画像を取得。
2. **Frontend**: 元画像の自動レイアウト解析と、グレースケール・コントラスト強調・自動回転後の単一ブロック解析を同じTesseract.js Web Workerで実行する。
3. **Frontend**: 2パスのOCR全文から店名・購入日・合計金額を抽出し、フォームへ自動入力する。「合計」が誤認識された場合は税込対象額や繰り返し出現する通貨額を補助候補にする。
4. **Frontend / Backend**: 店名とOCR全文を分類APIへ送り、推定カテゴリーをフォームへ初期設定する。
5. **Frontend**: ユーザーが確認・修正後、保存ボタンを押す。
6. **Backend**: 確認済みデータとOCR抽出値・自動分類結果を支出・修正履歴としてDBに保存する。

## 利用エンドポイント
- `GET /api/categories/`: 選択可能なカテゴリー一覧を取得する
- `POST /api/categories/classify/`: 店名・OCR全文からカテゴリーを自動分類する
- `POST /api/expenses/`: 確認済みの支出とOCR抽出値を保存する

## 注意点
- OCR解析時点ではDB保存しない。
- ユーザーが確認・修正して保存した後にDBへ登録する。
- OCRの読み取りミスに備えて、日付・店名・合計金額・カテゴリーは手動修正できるようにする。
- 保存時に、OCRの抽出値と修正後の支出値を修正履歴として保存する。
- レシート画像はブラウザ外へ送信・保存しない。
- 初回は日本語・英語の学習データをダウンロードするため、解析開始まで時間がかかる場合がある。
- 複数画像では同じWeb Workerを再利用する。
- 信頼度が70%未満の場合は、レシート画像との照合を促す警告を表示する。

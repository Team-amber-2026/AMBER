# 画面導線・ログアウト配置の確認（#32 / #43）

## 実装範囲

- 未ログインのトップ `/` と、ログイン必須のマイページ `/mypage` を追加。
- ログアウトはマイページだけに配置。ホームにユーザー情報を重複表示しない。
- 新規登録後はログイン画面へ進み、ログイン後にホームへ進む。
- 支出保存の連打を防ぎ、成功後は登録画面の履歴を保存完了画面で置き換える。
- 保存完了の再表示・再読み込みは保存APIを送信せず、保存情報のない直接アクセスは登録画面へ戻す。
- 外部API・DBの変更なし。PR #46を含むmain（`d15a317`）を基点とする。

## #30 / #31への引き継ぎ

本番反映後、テスト用アカウントで次を確認し、反映コミットと結果を記録する。

1. `/` から登録→ログイン→ホーム→マイページへ進める。
2. ログイン直後と、支出一覧・月次集計を経由した後の両方で、リロードせずログアウトできる。成功時はログイン画面へ戻り、ブラウザの戻る操作でも保護画面の情報を表示しない。
3. Safari通常／プライベート、Chrome通常／シークレット、Edge通常／InPrivateで、既定のCookie制限を維持して認証できる。
4. スマホ実機で画像選択・OCR・確認修正・保存・続けて登録・ホーム集計まで操作する。
5. 保存ボタンの連打、保存完了の再読み込み、履歴の戻る／進むで支出が重複しない。保存通信失敗時は入力内容を保持して再試行できる。
6. マイページだけにログアウトがあり、PC・スマホ実機で横スクロールや操作しづらい要素がない。

CSRFトークンの修正は#39、同一オリジン構成とCookieの検証は#41で追跡する。今回のブラウザ確認はローカルのモックAPIを利用しており、公開環境の認証・実機QAの完了を意味しない。
